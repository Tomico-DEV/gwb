# Geometric Workbench
![Rust](https://img.shields.io/badge/rust-%23000000.svg?style=for-the-badge&logo=rust&logoColor=white)
[![docs build](https://github.com/Tomico-DEV/gwb/actions/workflows/mdbook.yml/badge.svg)](https://github.com/Tomico-DEV/gwb/actions/workflows/mdbook.yml)

This is a rust implementation of Martti Mäntylä's Geometric Workbench, 
as described in [*An Introduction to Solid Modeling*](https://books.google.co.jp/books/about/An_introduction_to_solid_modeling.html?id=CJVRAAAAMAAJ&hl=en&redir_esc=y).

See the [docs](https://tomico-dev.github.io/gwb/) for more detail.
